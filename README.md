## 📂 Featured Projects

### 1. Healthcare Analytics Platform
 A relational database ecosystem designed to streamline and analyze hospital operations. This project bridges that gap by creating a unified data model that tracks the entire patient journey—from initial department assignment and physician matching to clinical encounters and ultimate financial billing resolution.
* **Clean Data Integrity:** Uses smart constraints to prevent missing or broken data loops.
* **Financial Ledger Visibility:** Features a solid billing system that automatically tracks insurance coverage vs. out-of-pocket patient costs.
* **Analytics Ready:** Optimized for quick, high-utility SQL joins and aggregations to power executive-level dashboards.
